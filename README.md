# UELuxy Brand Website

Responsive brand showcase website built with pure HTML, CSS, and JavaScript — no frameworks.

## About

A clean, modern brand presentation site created as a front-end development practice project.  
Focuses on visual hierarchy, product display, and responsive design for a fashion/lifestyle brand concept.

## Features

- Fully responsive layout
- Clean product showcase sections
- Custom CSS styling
- Vanilla JavaScript interactions
- Mobile-friendly design

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Project Structure

```
UELUXY/
├── index.html
├── style.css
├── script.js
└── images (background, products, etc.)
```

## How to Run Locally

```bash
git clone https://github.com/ankitsapkota2002-boop/UELuxy-brand-website.git
cd UELuxy-brand-website/UELUXY
# Open index.html in your browser
```
